## Installing the files

Sketchfab requires an authenticated user before it returns downloadable model archives. Download each selected model while signed in, choose the glTF/GLB download, convert to a single `.glb` if the archive contains `.gltf` plus external textures, and place the results in this directory using the exact filenames above.

Until a file is installed, the renderer intentionally keeps a procedural fallback car visible. This keeps development builds and tests usable without redistributing the original model files outside the author's download flow.
