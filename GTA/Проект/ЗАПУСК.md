# Portside: запуск

Эта папка — самостоятельная копия результата. Требуется Node.js 22.12+ и браузер с WebGL 2, клавиатура и мышь. Интернет нужен для первой установки зависимостей. Аккаунт и API-ключ для приложения не нужны.

1. Полностью распакуйте общий архив.
2. Откройте PowerShell в этой папке.
3. Выполните:

```powershell
npm.cmd ci
npm.cmd run dev -- --port 5181 --strictPort
```

Откройте http://127.0.0.1:5181/ . Сервер останавливается Ctrl+C. Если порт занят, выберите другой после `--port`. Повторная установка нужна только после изменения зависимостей.

## Проверки и production-версия

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview -- --port 5181 --strictPort
```

Архив включает готовый `dist` и исходный код. Для готового `dist` достаточно HTTP-сервера: из этой папки `python -m http.server 5181 --bind 127.0.0.1 --directory dist`, затем откройте тот же адрес. Двойной щелчок по HTML не заменяет HTTP-сервер.

## Управление

Нажмите Play, чтобы начать: мышь будет захвачена игрой, а курсор скрыт. Мышь поворачивает камеру по горизонтали и вертикали. Пешком W/S двигают персонажа вперёд/назад относительно камеры, A/D — влево/вправо. В машине W/S — газ/торможение и задний ход, A/D — руль; мышь позволяет независимо осматриваться.

Стрелки дублируют WASD; E — взаимодействие и вход/выход; Shift — бег; Space — тормоз; T — повтор миссии; C — расстояние камеры; N — большая карта; H — справка; M — звук. Esc — пауза и освобождение курсора для меню. Для продолжения нажмите Back to the city (или P). При потере фокуса игра автоматически ставится на паузу.

Оружие доступно пешком: 1 — нож, 2 — пистолет, 3 — автомат. ЛКМ — удар или выстрел; удерживайте ЛКМ для автоматического огня из автомата. ПКМ — прицеливание, R — перезарядка. Пистолет вмещает 12 патронов, автомат — 30; запас и ход перезарядки видны справа. В машине оружие убрано. Нажатия мыши в меню не вызывают атаку.

Убийство пешехода даёт три звезды розыска: полицейские преследуют игрока на машинах, выходят и открывают огонь. Следите за здоровьем слева внизу, используйте здания и машины как укрытия. Можно уйти от погони пешком или на машине. При нулевом здоровье персонаж возвращается в город через 4 секунды.

При трёх звёздах подкрепления постепенно увеличивают погоню до шести патрулей. Экипажи разгоняются на прямых, тормозят перед поворотами и пытаются перехватить машину на следующих перекрёстках. Чтобы сбросить розыск, скройтесь из поля зрения: полиция проверит последнее известное место и соседние улицы. Повторное обнаружение обнуляет прогресс ухода. Статус справа показывает преследование или поиск и число действующих патрулей.

## Состав и происхождение

`src` — исходники, `tests` — тесты приложения, `public` — локальные ресурсы, `verification` — новый протокол проверки копии. Первоначальное описание сохранено в `docs/ORIGINAL_README.md`; упоминания общей папки и других приложений в нём исторические.

При упаковке изменены только точка входа и конфигурация сборки, чтобы приложение открывалось по `/` и не зависело от соседних результатов. Игровая логика сохранена. Зависимости и lock взяты из зафиксированного общего проекта b774e63, до добавления Phaser для Emberwild. Исходный рабочий проект не изменялся.
