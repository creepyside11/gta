# Portside для Android

[Скачать APK](./portside-android-debug.apk?raw=true)

APK содержит игру из исходников репозитория и работает без Vercel и интернета. Требуются Android 8.0+, актуальный Android System WebView с WebGL 2 и устройство с OpenGL ES 3.0. Ориентация — альбомная, управление — сенсорное. Кнопка «Назад» приостанавливает игру и предлагает выход.

Для установки скачайте APK и откройте его на Android, разрешив установку для используемого браузера или файлового менеджера.

Это подписанная **debug-сборка для установки и тестирования**, не релиз для Google Play. Ключ создаётся Android SDK во время сборки и не публикуется. При установке следующей сборки Android может потребовать удалить предыдущую из-за смены тестового ключа. Состояние текущей игровой сессии не сохраняется после закрытия приложения.

Рядом с APK публикуются SHA-256 и `build-info.json` с точным коммитом исходников. GitHub Actions проверяет веб-тесты, сборку, Android lint, подпись и наличие игровых ресурсов в APK. Эти проверки не заменяют проверку производительности на реальном телефоне.

## Повторная сборка

Workflow **Build and publish Android APK** запускается при изменениях игры или Android-проекта в `main`, а также вручную из Actions. После успешной сборки APK автоматически коммитится в эту папку; копия доступна в артефактах workflow.

Локально нужны Node.js 22, JDK 17, Gradle 8.9, Android SDK 35 и Build Tools 35.0.0:

```sh
npm ci --prefix 'GTA/Проект'
npm run build --prefix 'GTA/Проект'
gradle --no-daemon -p android assembleDebug
```

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`.
