# Portside / GTA

Исходники из `GTA.zip` распакованы в [`GTA/Проект`](GTA/Проект). Исходный архив сохранён; актуальная версия с сенсорным управлением находится в распакованной папке.

## Запуск

Нужен Node.js 22.12+.

```sh
cd "GTA/Проект"
npm ci
npm run dev -- --host 0.0.0.0
```

На телефоне или планшете в той же Wi-Fi сети откройте адрес компьютера с портом, который выведет Vite (обычно `http://192.168.x.x:5173`). Для статического хостинга выполните `npm run build` и разместите содержимое `dist`.

## Телефон и планшет

Сенсорные кнопки появляются автоматически на устройствах с поддержкой касаний. Нажмите **Play** — захват мыши не требуется. Работают портретная и альбомная ориентации; в альбомной больше места для обзора.

- Левый стик: движение пешком; газ, задний ход и поворот за рулём.
- Свайп по свободной области экрана: поворот камеры.
- **Fire / Aim**: атака и прицеливание (удерживайте, можно одновременно с движением и обзором).
- **Run / Brake**: бег пешком или тормоз в машине.
- **E · Use / Car**: взаимодействие, начало доставки, вход и выход из машины.
- **1 / 2 / 3**: нож, пистолет, автомат; **R · Reload**: перезарядка.
- **Camera**: расстояние камеры; **Restart**: перезапуск доставки.
- Кнопки сверху: звук, пауза, справка. Нажатие на мини-карту меняет её размер.

При паузе, потере фокуса и уходе в другую вкладку ввод сбрасывается. На компьютере доступны исходные клавиатура и мышь.

## Проверки

```sh
npm run build
npm test
```

Если среда запрещает IPC-сокеты для CLI `tsx`, тесты можно запустить без него:

```sh
node --import tsx --test tests/*.test.ts
```
